2. FULL DESCRIPTION / LONG DESCRIPTION
============================================================

ভোলাবাসী হলো ভোলার মানুষের জন্য তৈরি একটি আধুনিক local super app, powered by Sohoj IT। এক অ্যাপ থেকেই আপনি খাবার অর্ডার, স্থানীয় সেবা খোঁজা, মার্কেটপ্লেস, ব্যবসা ডিরেক্টরি, কর্মী খোঁজা, প্রোপার্টি, স্বাস্থ্য, শিক্ষা, জরুরি তথ্য, নোটিফিকেশন এবং সাপোর্ট সুবিধা ব্যবহার করতে পারবেন।

মূল সুবিধাসমূহ:

• ফুড ডেলিভারি
পছন্দের খাবার খুঁজুন, রেস্টুরেন্ট দেখুন, কার্টে যোগ করুন, ডেলিভারি লোকেশন ম্যাপ থেকে নির্বাচন করুন এবং অর্ডার ট্র্যাক করুন।

• পেমেন্ট সুবিধা
রেস্টুরেন্ট অনুযায়ী Cash on Delivery, manual bKash বা manual Nagad পেমেন্ট নির্দেশনা দেখা যায়। প্রয়োজন হলে transaction ID ও payment status দেখা যাবে।

• লাইভ ডেলিভারি ট্র্যাকিং
রাইডার খাবার নেওয়ার পর অর্ডার অনুযায়ী ডেলিভারি progress এবং লোকেশন আপডেট দেখা যাবে। লোকেশন আপডেট না থাকলে last updated status দেখানো হয়।

• স্থানীয় সার্ভিস
ব্যবসা, হাসপাতাল, ডাক্তার, হোটেল, রেস্টুরেন্ট, শিক্ষা, কুরিয়ার, বিদ্যুৎ অফিস, জরুরি নম্বরসহ প্রয়োজনীয় স্থানীয় তথ্য এক জায়গায়।

• মার্কেটপ্লেস ও পোস্টিং
ব্যবহারকারী প্রয়োজন অনুযায়ী আইটেম, সার্ভিস বা লোকাল পোস্ট খুঁজতে ও যোগ করতে পারবেন।

• রাইডার ও পার্টনার সিস্টেম
রাইডার registration, KYC, delivery request, wallet, earning এবং delivery proof flow support করা হয়েছে।

• অ্যাকাউন্ট ও নিরাপত্তা
OTP verification, password change, login devices, notification settings, support এবং account deletion request flow আছে।

• বাংলা UI
ভোলার সাধারণ ব্যবহারকারীর জন্য সহজ, পরিষ্কার ও বাংলা ভাষাভিত্তিক user experience।

গোপনীয়তা ও নিরাপত্তা:
ভোলাবাসী শুধুমাত্র সেবা দেওয়ার জন্য প্রয়োজনীয় তথ্য সংগ্রহ করে, যেমন account information, delivery address, location, uploaded media/document, order details, support request এবং device token for notification. Data in transit encrypted connection এর মাধ্যমে পাঠানো হয়। ব্যবহারকারী চাইলে support-এর মাধ্যমে account deletion request করতে পারবেন।

3. DATA SAFETY FORM - HIGH LEVEL ANSWERS
============================================================

Play Console path:
Policy and programs > App content > Data safety > Start

Data collection and security:

Question: Does your app collect or share any of the required user data types?
Answer: Yes

Question: Is all of the user data collected by your app encrypted in transit?
Answer: Yes
Reason: App uses HTTPS API endpoints, Firebase, Google services, and secure network requests. Make sure production API remains HTTPS-only.

Question: Do you provide a way for users to request that their data is deleted?
Answer: Yes
Deletion URL/page:
https://bholavashi.site/delete-account/

Question: Is data collection required or optional?
Recommended answer: Some data is required, some is optional.
Explanation:
- Account/login/order data is required for core app functionality.
- Profile photo, KYC document, support attachment, delivery proof, notification permission, and precise location permission are provided only when the user chooses or when needed for delivery/rider features.

4. DATA TYPES TO SELECT
============================================================

Select the following data types in Google Play Data Safety.

------------------------------------------------------------
A. Location
------------------------------------------------------------

Select:
1. Approximate location
2. Precise location

Collected: Yes
Shared: Yes, only with service providers needed for app functionality, such as backend server, map/routing services, restaurant/rider/admin delivery flow.
Processed ephemerally: No, not always. Delivery and rider location can be stored for order/rider tracking.
Required or optional: Optional for general app browsing, required for location-based delivery/rider features.

Purposes:
- App functionality
- Personalization
- Analytics
- Fraud prevention, security, and compliance

Why:
- Customer selects delivery location.
- Restaurant/customer/admin/rider can view delivery route/location.
- Rider location is used for dispatch and live tracking.
- Distance is used for delivery fee and rider matching.

------------------------------------------------------------
B. Personal Info

4. Address

Processed ephemerally: No

6. SHARING DECLARATION
============================================================

In Google Play, "sharing" can include transferring user data to third parties. For this app, choose "Yes" for sharing where the form asks per selected data type if applicable.

Mention/reason internally:
- Google Maps / Google services: map display, location/routing, Google login.
- Firebase Cloud Messaging: push notification device tokens and notification delivery.
- Meta SDK: app events, install campaign measurement, advertising analytics.
- Hosting/backend providers: app API, database, media storage, logs.
- SMS/email gateway providers: OTP, password reset, transactional messages.
- Restaurant owners/riders/admin: only operational order/delivery details needed to complete service.

Do not declare sale of user data.
Do not say data is shared for unrelated third-party resale.
